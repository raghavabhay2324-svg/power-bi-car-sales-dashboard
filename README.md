#power-bi-car-sales-dashboard
 Power BI Sales Dashboard

 Project Overview
This project is an interactive Sales Analysis Dashboard created using Microsoft Power BI Desktop.

Project Objectives
- Analyze sales and revenue performance.
- Identify trends over time.
- Compare sales across categories.
- Present important business insights visually.

 Charts and Visualizations
- Line Chart: Shows sales or revenue trends over time.
- Clustered Bar Chart: Compares values across categories.
- Donut Chart: Displays the distribution of sales by category.
- KPI Cards: Display key performance indicators.
- Slicers: Allow users to filter the dashboard interactively.

 Tools Used
- Microsoft Power BI Desktop
- Data Visualization
- Data Analysis

 Project File
The Power BI report (.pbix) is available in this repository. Download it and open it using Power BI Desktop.
